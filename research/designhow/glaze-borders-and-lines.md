# Borders and lines

One hairline weight, from the faint card edge to the field line that darkens on focus.

## Steps

- `line-faint`
- `line`
- `line-control`
- `line-focus`
- `line-strong`

| Token | Light value | Used by |
| --- | --- | --- |
| `--line-faint` | `rgb(5 5 5 / 0.06)` | card, panel, row rule |
| `--line` | `rgb(5 5 5 / 0.10)` | menu, popover, dialog, separator |
| `--line-control` | `rgb(5 5 5 / 0.15)` | input, select, textarea |
| `--line-focus` | `rgb(5 5 5 / 0.32)` | input, select, textarea, prompt input |
| `--line-strong` | `rgb(5 5 5 / 0.45)` | checkbox, radio, switch off |
