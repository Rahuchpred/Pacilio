## Sizes

Add keyAdd keyAdd key

| Where | Size | Line at regular |
| --- | --- | --- |
| A small control, a tag | 12px | 0.75px |
| A control | 14px | 0.875px |
| A large control | 16px | 1px |
| On its own | 20 or 24px | 1.25 or 1.5px |

## Weights

lightregularboldfill

| Weight | Where |
| --- | --- |
| regular | every control, the default |
| light | dense rows and tables, 14px and up |
| bold | rarely: a 12px glyph that must hold on glass |
| fill | only an icon toggle that is on |
