# Radius

Pills for every one-line control, 14 and 11 for the card, 10 for overlays, 6 for tags.

## Scale

Pill

rounded-pill, 999px

shell 14px, panel 11px

rounded-overlay, 10px

Tag

rounded-tag, 6px

| Class | Radius | Used by |
| --- | --- | --- |
| `rounded-pill` | 999px | button, input, select, segmented control, chip, badge |
| `shell` | 14px | card |
| `panel` | 11px | card panel |
| `rounded-overlay` | 10px | menu, popover, dialog, textarea, code block |
| `rounded-tag` | 6px | menu item, tag in a row, kbd |
